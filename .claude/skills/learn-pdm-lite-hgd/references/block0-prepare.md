## EXPLAIN

### 1. 오늘 쓰는 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 데이터 |
| 진동(mm/s) | 베어링·회전체 마모, 정렬 불량의 전조를 보는 값. 갑작스러운 증가·추세적 상승이 전조 |
| 가상 데이터 | 실습용으로 만든 값. 실제 설비 값이 아니다 |

오늘 파일은 설비 2대(A 프레스 메인모터, B 차체 용접로봇 감속기) × 25시점(20분 간격, 2026-09-15 08:00~16:00)이다. 단위(℃, mm/s, bar)와 측정 주기를 먼저 확인한다 — 단위가 섞이면 이상 판단이 흔들린다.

### 2. 왜 준비부터 하는가

| 기준 | 원본 파일을 바로 수정 | 작업 폴더에 복사해서 사용 |
|---|---|---|
| 원본 | 망가지면 복구 어려움 | 항상 그대로 남는다 |
| 결과물 | 어디 있는지 흩어짐 | 한 폴더에 모인다 |

## EXECUTE

```
다음 순서로 진행해 줘. 원본 파일은 수정하지 말고, 비밀번호나 키는 요구하지 마.
1. 홈 폴더에 pdm-lite 폴더를 만들고 그 안에 data 폴더를 만들어 줘.
2. 이 스킬의 {SKILL_DIR}/assets/lab/Day5_설비센서_50건_가상.csv 를 pdm-lite/data/ 로 복사해 줘. ({SKILL_DIR}은 실제 경로로 바꿔서 보여 줘)
3. 복사한 CSV의 열 이름, 행 수, 설비 이름, 단위(℃, mm/s, bar), 시간 간격을 확인해서 pdm-lite/env_check.txt 에 적어 줘.
4. 끝나면 "새 세션 → Local → pdm-lite 폴더 선택"으로 그 폴더에서 새 세션을 여는 방법을 안내해 줘.
```

### 확인할 것 (Phase B)

- `~/pdm-lite/data/Day5_설비센서_50건_가상.csv` 가 있고 50행(설비 2대 × 25시점)이다.
- `~/pdm-lite/env_check.txt` 에 단위 mm/s·℃·bar 와 20분 간격이 적혀 있다.
- 수강생이 `pdm-lite` 폴더에서 새 세션을 열었는지 물어보고, 열었으면 Block 1로 간다.
