# Block 2: 공개

> **Phase A 시작 시 그대로 출력한다:**
> ```
> 📖 공식 문서: https://docs.github.com/en/pages/quickstart
> ```

## EXPLAIN

### 1. 정의

| 용어 | 뜻 |
|---|---|
| GitHub Pages | GitHub 저장소의 HTML 파일을 인터넷 주소(URL)로 공개해 주는 기능 |
| 공개 저장소 | 누구나 볼 수 있는 저장소. 올린 파일은 누구나 볼 수 있다 |

### 2. 왜 공개하는가

| 기준 | 파일을 메신저로 전달 | URL로 공개 |
|---|---|---|
| 받는 사람 | 파일을 내려받아 열어야 한다 | 링크만 누르면 본다 |
| 수정 | 버전이 여러 개로 갈라진다 | 같은 주소에서 최신 버전 |

공개 전에 확인할 것: 오늘 올리는 파일은 가상 데이터로 만든 `index.html` 하나다. 회사 내부 자료나 개인정보는 공개 저장소에 올리지 않는다.

## EXECUTE

GitHub 로그인이 필요하면 **수강생이 직접** 한다. 비밀번호나 토큰을 Claude에게 알려 주지 않는다.

```
pdm-lite/index.html 을 GitHub Pages로 공개해 줘. 비밀번호나 토큰은 나에게 요구하지 마.
1. GitHub 로그인 상태를 확인하고, 안 되어 있으면 내가 직접 로그인하는 방법만 안내해 줘.
2. 공개하기 전에 올릴 파일 목록(index.html, README.md)과 저장소 이름(learn-pdm-lite-내GitHub아이디)을 보여 주고 내 확인을 받아 줘.
3. 확인하면 공개 저장소를 만들어 index.html 과 한 줄짜리 README.md 만 올리고 GitHub Pages를 켜 줘. CSV는 올리지 마.
4. 공개 주소를 알려 주고, 동료에게 보낼 한 줄 메시지(무엇을 보여 주는 그래프인지)를 만들어 줘.
```

### 확인할 것 (Phase B)

- 수강생이 올리기 전에 파일 목록을 확인했는가(확인 없이 올렸다면 알려 준다).
- 저장소에 `index.html` 과 `README.md` 만 있고 CSV·개인정보가 없는가.
- 공개 주소를 열면 설비 A·B 진동 그래프 한 장이 보이는가(Pages 반영에 1~2분 걸릴 수 있다).
- GitHub 로그인이 안 돼 공개하지 못했다면 `index.html` 을 그대로 보관한 것으로 마친다.

막히면 "공개 주소가 안 열려. 원인을 찾아서 고쳐 줘"라고 Claude Code에게 시킨다. 정답은 "정답 보기" 요청이 있을 때만 연다.
