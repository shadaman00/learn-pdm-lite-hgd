# 예지보전 라이트 — 노이즈 vs 추세 (10분)

설비 2대의 진동 데이터를 평상 범위(평균 ± 2표준편차)로 점검해 "정비 신호는 어느 쪽인가"를 판단하고, 끝나면 그래프 한 장짜리 대시보드 주소가 남는다. 이 스킬이 곧 수업이다. Claude가 설명하고, 수강생은 **프롬프트를 붙여 넣고 결과를 확인**한다. 설치·실행·파일 만들기·오류 해결은 Claude Code가 한다. GitHub 로그인만 수강생이 직접 한다(비밀번호는 Claude에게 입력하지 않는다).

이 스킬이 호출되면 아래 **STOP PROTOCOL**을 반드시 따른다.

## STOP PROTOCOL — 최우선 규칙

### 각 블록은 2턴으로 진행한다

```
┌─ Phase A (첫 번째 턴) ─────────────────────────────────┐
│ 1. 블록 파일 상단의 "📖 공식 문서" 줄을 그대로 출력한다          │
│ 2. EXPLAIN 섹션을 읽고 설명한다                              │
│ 3. EXECUTE 섹션을 읽고 붙여 넣을 프롬프트를 코드 블록으로 준다     │
│ 4. 종료 문구를 출력하고 ⛔ STOP                              │
│                                                          │
│ ❌ 퀴즈 출제, QUIZ 섹션 읽기                                 │
│ ❌ AskUserQuestion 호출                                    │
│ ❌ "실행해 보셨나요?" 질문                                   │
└──────────────────────────────────────────────────────────┘
        ⬇ 수강생이 프롬프트를 실행하고 "완료"·"다음"을 입력
┌─ Phase B (두 번째 턴) ─────────────────────────────────┐
│ 1. EXECUTE의 "확인할 것"으로 결과를 점검한다 (파일·명령으로 직접) │
│ 2. QUIZ 섹션을 읽고 AskUserQuestion으로 출제한다              │
│ 3. 정답·해설을 준다 (오답이면 왜 다른 보기가 틀렸는지도)          │
│ 4. AskUserQuestion으로 다음 블록 진행 여부를 묻는다             │
└──────────────────────────────────────────────────────────┘
```

### Phase A 종료 문구 (그대로 출력)

```
---
👆 위 프롬프트를 이 창에 붙여 넣어 실행해 보세요.
결과를 확인했으면 "완료" 또는 "다음"이라고 입력해 주세요.
```

이 문구 뒤에는 어떤 도구 호출이나 텍스트도 출력하지 않는다.

### 수강생이 Phase A의 프롬프트를 붙여 넣었을 때

그 프롬프트는 실습 지시다. 수업 진행을 멈추고 **그대로 수행한다**. 끝나면 결과를 짧게 보고하고 "완료라고 입력하면 다음으로 넘어갑니다"라고 덧붙인다. 이것은 Phase B가 아니다.

## 진행 규칙

- 한 번에 한 블록. "다음", "skip", 블록 번호로 이동한다.
- 수강생에게 터미널 명령을 직접 치게 하지 않는다. 필요한 일은 붙여 넣을 **한국어 프롬프트**로 준다.
- **기본은 Claude 데스크톱 앱(Code 탭)이다.** 폴더는 "새 세션 → Local → 폴더 선택", 허용은 화면의 허용 버튼. 수강생이 VS Code를 쓴다고 하면 그때부터 VS Code 기준으로 안내한다.
- 데이터는 모두 **가상 데이터**다. 회사 내부 자료나 개인정보는 공개 저장소에 올리지 않는다.
- 원본에 없는 내용을 지어내지 않는다. 추정은 "추정"이라고 말한다.
- Claude Code 기능 질문은 claude-code-guide 에이전트나 공식 문서로 확인한 뒤 답한다.
